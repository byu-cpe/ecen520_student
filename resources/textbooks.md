# Course Textbooks

The reading assignments for this course come from the following two textbooks.
Both are available as e-books through the BYU library (you must be logged in to the BYU library to access them).
If a library link below does not work, search the [BYU Library](https://lib.byu.edu) for the book title.

## RTL Hardware Design Using VHDL

Pong P. Chu, *RTL Hardware Design Using VHDL: Coding for Efficiency, Portability, and Scalability*, Wiley, 2006.

* [BYU Library e-book](https://lib.byu.edu/search/byu/record/cat.3578786.item.31197226570247)
* DOI: [10.1002/0471786411](https://doi.org/10.1002/0471786411)

## SystemVerilog for Verification

Chris Spear and Greg Tumbush, *SystemVerilog for Verification: A Guide to Learning the Testbench Language Features*, 3rd edition, Springer, 2012.

* [BYU Library e-book](https://lib.byu.edu/search/byu/record/cat.3995831.item.31197229257024)
* DOI: [10.1007/978-1-4614-0715-7](https://doi.org/10.1007/978-1-4614-0715-7)
